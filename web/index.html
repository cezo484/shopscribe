How it works

Every report is written through one of three paths. The badge on each report says which one was used.

  1. On-device. Chrome's Prompt API runs Gemini Nano in the browser. The note stays on the device and the report costs nothing. Needs Chrome on desktop, version 139 or newer, with the on-device model downloaded.
  2. Cloud. When the on-device model is not available, the note goes to Firebase AI Logic, which calls a cloud Gemini model through the Gemini Developer API backend. Needs a Firebase project (see the README).
  3. Local. When neither model path is available, a small rule-based formatter on this page structures the note. The demo always works, even with no setup at all.

If a path fails, the next one is tried automatically. The attempt log under the badge records what happened.
